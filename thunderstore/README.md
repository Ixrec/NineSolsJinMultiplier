# Nine Sols Jin Multiplier

A Nine Sols mod that that changes how much jin (money) the player receives from various sources.

Assuming you also have the BepinExConfigurationManager mod, press F1 in-game to customize the following settings:
- Jin Drop Multiplier
- Transmute Unto Wealth Multiplier
- Recycling Multiplier

These all default to 1x (i.e. no effect) so remember to customize them.
